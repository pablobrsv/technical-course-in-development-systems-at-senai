# 💻 Técnico em Desenvolvimento de Sistemas | SENAI

Repositório dedicado ao armazenamento de códigos, projetos e materiais práticos desenvolvidos durante o curso técnico em Desenvolvimento de Sistemas pelo SENAI.

---

## 📚 Grade Curricular e Conteúdos

### 1. Fundamentos da Programação e Lógica

* **Lógica de Algoritmos:** Estruturas condicionais, laços de repetição (`while`, `for`) e tratamento de variáveis.
* **Python & Portugol:** Introdução à sintaxe, manipulação de dados básicos e automação de scripts.

### 2. Bancos de Dados e Modelagem

* **Modelagem Relacional:** Conceitos de tabelas, chaves primárias/estrangeiras e normalização.
* **SQL (PostgreSQL):** Sublinguagens DDL, DML, DQL e TCL, consultas com Joins, CTEs e Window Functions.

### 3. Desenvolvimento Web (Front-end e Back-end)

* **Estruturação Web:** HTML5 e estilização com CSS3.
* **Interatividade:** Fundamentos de JavaScript para o navegador.
* **Desenvolvimento de APIs:** Criação de rotas e integração com servidores.

### 4. Engenharia de Software e Versionamento

* **Git e GitHub:** Controle de versão, criação de branches, pull requests e documentação em Markdown.
* **Qualidade e Testes:** Boas práticas de código limpo (*Clean Code*) e depuração de erros.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagens:** Python, SQL, HTML/CSS/JavaScript.
* **Banco de Dados:** PostgreSQL, pgAdmin.
* **Ferramentas:** VS Code, Git, GitHub.
